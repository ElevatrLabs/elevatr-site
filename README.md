# FlaskIt

A browser physics game: drop objects into a flask, merge matching forms, and reach the final form. Build your own worlds with images and short sound clips.

Play at https://flaskit.elevatr.app/

This repository contains the production static release for GitHub Pages. Physics is compiled from Rust/Rapier to WebAssembly; rendering uses PixiJS/WebGL.

The original flask body proportions, 10% progression around the selected midpoint size, size-aware inlet losses, focus dashboard, automated play, and single-game downloads are included.

Google web-ad placements are implemented. Live serving is disabled until AdSense for Content/site approval, H5 Games access, web-banner slot IDs, and the Google consent message are configured. Public settings are in `monetization.json`; they contain no credentials. Do not substitute native AdMob unit IDs for web ad units. The account ownership meta tag and ads.txt are included for setup.

Privacy: https://flaskit.elevatr.app/privacy.html
